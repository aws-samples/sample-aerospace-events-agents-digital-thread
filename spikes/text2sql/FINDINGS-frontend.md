# Spike — Frontend UX for "Ask the datalake" (NL→SQL console)

**Status:** THROWAWAY SPIKE / design-only. No production components modified.
**Question:** What is the best UX for an NL→SQL console that maximizes the "wow, it's a real
query engine" demo effect while staying honest (show the generated SQL, don't hide failures)?

---

## 1. Recommended UX (the shape of the wow)

The "wow" comes from **watching a plain-English question become real SQL that really runs on
real infrastructure** — not from a pretty answer appearing. So the console is built to make the
*machinery visible*, in three honest beats:

1. **Ask** — one big NL input + a row of example-question chips. Chips are the demo's safety net:
   they seed known-good questions so the presenter never fights a blank box on stage.
2. **Two-phase loading** — `generating…` (Claude writes SQL) → `querying Athena…` (Iceberg scan).
   Two distinct phases sell the two-step architecture (LLM plans, engine executes). Even though
   `useDatalake.run()` is a single round-trip, we stage the label transition on a timer so the
   audience *sees* both steps. (Honest: both really happen server-side; we only pace the label.)
3. **Reveal** — the generated SQL appears in a monospace, collapsible panel with a copy button,
   labelled **"generated by Claude, executed on Athena over Iceberg"**, then the results table
   with a live latency badge (`Athena over Iceberg · {ms}ms`) and `row count · scanned bytes`.

This ordering matters: **SQL is revealed BEFORE (or above) the table**, never tucked away after.
Transparency is the feature, so the SQL is a first-class citizen, expanded by default on the
first run of a session (so the audience sees it at least once), collapsible thereafter.

### Example-question chips (seeded from the ARES-1 demo domain)

Pick 5 that map to queries the Athena backend can actually satisfy (NCR/EVM/parts tables):

1. "Critical NCRs by supplier, last 30 days"
2. "NCR trend by severity over the last quarter"    <- time-series -> chart-toggle candidate
3. "Which parts have the most defects?"             <- category+count -> chart-toggle candidate
4. "Earned-value trend for ARES-1 wing box"         <- time-series -> chart-toggle candidate
5. "Open HITL decisions awaiting sign-off"

Chips are `<button>`s; clicking one fills the input **and** auto-submits (one gesture on stage).

## 2. Generic results table (arbitrary rows -> columns)

`useDatalake.run()` returns `rows: any[]` of flat objects. Render generically:

- **Columns** = `Object.keys(rows[0])` (first row is the schema oracle). Empty rows -> empty state.
- **Header cells**: `text-text-muted`, `font-mono`, uppercase, `text-[10px]`, left-aligned.
- **Numeric cells right-aligned**: a cell is numeric when `typeof v === 'number'` OR
  (`typeof v === 'string'` && `v.trim() !== '' && !isNaN(Number(v))`). Right-align the whole
  column if a **majority** of sampled cells are numeric (avoids a stray null flipping alignment).
  Numbers render `font-mono` + `tabular-nums` and locale-grouped (`Number(v).toLocaleString()`).
- **Long / JSON payload cells**: if a value is an object/array -> `JSON.stringify`; if a string is
  `> 60` chars -> truncate with an ellipsis, `title={full}` for hover, `max-w-[280px] truncate
  font-mono`. Keeps rows one-line-tall so the table reads like a real SQL console, not a wall of text.
- **null / undefined** -> dim placeholder (`text-text-muted`) so empty cells are legible, not blank.
- **Zebra + hover**: `even:bg-surface-secondary`, `hover:bg-surface-tertiary`. Sticky header.
- **Row cap**: render first 100 rows; footer note "showing 100 of N" (demo tables aren't huge,
  but this stops a runaway scan from freezing the browser). Full N still shown in the meta badge.

### Optional chart toggle — heuristics (describe, don't overbuild)

Offer a **Table | Chart** segmented toggle *only when the shape is chartable*. Detect from the
generic rows (no backend hint needed):

- **Time series** -> columns include a date-like key (`/date|day|month|week|ts|time/i` and values
  parse as dates) + at least one numeric column -> **line/area chart** (x = date, y = numeric).
- **Category + count** -> exactly one non-numeric (dimension) column + exactly one numeric
  (measure) column, and `rows.length <= 25` -> **horizontal bar chart** (sorted desc by measure).
- Otherwise -> **Table only**, hide the toggle. Never guess a chart for wide/ambiguous shapes.

Reuse the existing `recharts` + token styling already proven in `NcrTrendChart.tsx`
(`var(--color-*)` for grid/tick/tooltip, `JetBrains Mono` ticks). Default view is always **Table**
— the chart is the flourish, the table is the truth. Keep the chart component tiny (~80 lines) or
skip it in the walking skeleton; it's a pure enhancement.

## 3. Error UX — make failure legible, never blank

Two failure classes, both must **still show the generated SQL** (that's the honesty contract):

- **Generation produced a non-SELECT / rejected query** — backend returns the SQL it built plus a
  guard error (`useDatalake` already surfaces the Lambda body, e.g. *"Only SELECT queries are
  allowed"*). Show the SQL panel (auto-expanded) + a red error banner beneath it.
- **Athena execution error** (bad column, syntax, timeout) — show the SQL panel (auto-expanded) +
  the Athena error text verbatim in the banner. The audience sees *what ran* and *why it failed* —
  which is more convincing of a real engine than a demo that only ever shows happy paths.

Error banner uses the established pattern: `bg-status-error-subtle border border-status-error/20
rounded-xl p-4`, text `text-status-error-text`, an `AlertTriangle` lucide icon, and the raw error
in `font-mono text-[12px]`. **Never** render a bare empty table or a silent no-op on error.

Empty-but-successful result (`rows.length === 0`, no error) is a *third, distinct* state:
"Query ran, 0 rows" in `text-text-muted font-mono` — success styling, not error styling. This
prevents the classic demo-review trap of a green success masking empty data.

---

## 4. Honesty / demo-review guardrails (non-negotiable)

These exist specifically to survive a `demo-review` pass:

1. **The SQL shown IS the SQL executed.** Render `result.generatedSql` returned by the backend —
   never a client-side reconstruction, never a hard-coded pretty string. If the field is missing,
   show "SQL unavailable" rather than fabricating one. One source of truth.
2. **Provenance label, always visible on the SQL panel:**
   *"generated by Claude, executed on Athena over Iceberg"* — two distinct actors, explicit.
3. **Live latency badge** = `result.executionMs` from the actual query (same
   `Athena over Iceberg · {ms}ms` pattern as `NcrTrendChart`). Not a constant, not a fake timer.
4. **Row count + scanned bytes** in the results meta line: `{rows.length} rows · {scannedBytes}
   scanned` (bytes from `result.scannedBytes`/`scannedRows` if present; **omit the clause entirely
   if absent** — never show `undefined` or a made-up number). Real engine -> real cost signal.
5. **The two-phase loading label is paced, but both phases are real** — Claude generation and
   Athena execution both occur server-side. We only stage the *label* transition; we do not fake
   either step. (Documented here so a reviewer knows the timer is cosmetic pacing, not deceit.)
6. **No mock fallback in the console.** `useDatalake` already returns an explicit
   "API Gateway not configured" error rather than fabricating rows (unlike `useHistoricalData`'s
   mock path). Keep it that way — a NL->SQL console that silently mocks would fail demo-review.

## 5. Component tree + prop contracts (TS)

```
AskDatalakePage                     (page: header, owns useDatalake + question state + phase)
|- QuestionInput                    (NL textbox + Ask button; Enter submits)
|- ExampleChips                     (row of seed-question buttons; click -> fill + submit)
|- QueryPhaseIndicator              (idle | generating | querying | done | error strip)
|- GeneratedSqlPanel                (collapsible mono SQL + copy + provenance label)
|- ResultMeta                       (row count . scanned bytes . Table|Chart toggle)
|- ResultView
   |- ResultsTable                  (generic rows->columns, right-align numbers, truncate)
   |- ResultsChart                  (optional; time-series line / category bar via recharts)
   |- ErrorBanner / EmptyState      (failure & 0-row states)
```

### Types

```ts
// Backend op result (text2sql). Mirrors the shape the task specified.
export type Text2SqlResult = {
  question: string;         // echoed NL question
  generatedSql: string;     // THE sql that was executed — single source of truth
  data: Row[];              // result rows
  executionMs: number;      // real Athena wall-time
  scannedBytes?: number;    // optional cost signal; omit clause if absent
};

export type Row = Record<string, string | number | boolean | null>;

type QueryPhase = 'idle' | 'generating' | 'querying' | 'done' | 'error';

// --- component props ---
type QuestionInputProps = {
  value: string;
  onChange: (v: string) => void;
  onSubmit: () => void;
  disabled: boolean;               // true while phase is generating|querying
};

type ExampleChipsProps = {
  questions: string[];             // the 5 seed questions
  onPick: (q: string) => void;     // fills input AND submits
  disabled: boolean;
};

type QueryPhaseIndicatorProps = { phase: QueryPhase };

type GeneratedSqlPanelProps = {
  sql: string | null;              // result.generatedSql; null -> "SQL unavailable"
  defaultOpen?: boolean;           // true on first run of the session
};

type ResultMetaProps = {
  rowCount: number;
  scannedBytes?: number;           // omit the "· N scanned" clause when undefined
  executionMs?: number;
  view: 'table' | 'chart';
  chartable: boolean;              // toggle only shown when heuristic says so
  onViewChange: (v: 'table' | 'chart') => void;
};

type ResultsTableProps = { rows: Row[] };
type ResultsChartProps = { rows: Row[] };     // component decides line vs bar from shape
type ErrorBannerProps  = { sql: string | null; error: string };
```

### i18n note (keys only — no `useI18n` hook exists in the repo yet)

The existing pages (`DigitalThreadPage`, `NcrTrendChart`) use **hard-coded English strings**;
there is no `useI18n()` / `en.json` in `src/frontend/src` today (CLAUDE.md lists i18n as a
convention, but it's aspirational here). For the spike, hard-code English to match the codebase.
If i18n lands later, the keys would be: `datalake.title`, `datalake.subtitle`,
`datalake.placeholder`, `datalake.ask`, `datalake.phase.generating`, `datalake.phase.querying`,
`datalake.sql.label` ("generated by Claude, executed on Athena over Iceberg"), `datalake.sql.copy`,
`datalake.results.meta`, `datalake.results.empty`, `datalake.error.title`, and one key per
`datalake.examples.*` chip.

## 6. Skeleton of the main component (reference — NOT in src/)

```tsx
// spike reference only — real build target: src/frontend/src/pages/AskDatalakePage.tsx
import { useState, useCallback } from 'react';
import { Search, Loader2, Copy, Check, ChevronDown, ChevronRight, AlertTriangle, Sparkles, Database } from 'lucide-react';
import { useDatalake } from '../hooks/useDatalake';

const EXAMPLES = [
  'Critical NCRs by supplier, last 30 days',
  'NCR trend by severity over the last quarter',
  'Which parts have the most defects?',
  'Earned-value trend for ARES-1 wing box',
  'Open HITL decisions awaiting sign-off',
];

type Phase = 'idle' | 'generating' | 'querying' | 'done' | 'error';

export function AskDatalakePage() {
  const { rows, loading, error, executionMs, scannedRows, run } = useDatalake();
  const [question, setQuestion] = useState('');
  const [phase, setPhase] = useState<Phase>('idle');
  const [sql, setSql] = useState<string | null>(null);
  const [firstRunDone, setFirstRunDone] = useState(false);

  const ask = useCallback(async (q: string) => {
    const text = q.trim();
    if (!text) return;
    setQuestion(text);
    setPhase('generating');
    setSql(null);
    // Cosmetic pacing: show "generating" briefly, then "querying". Both steps
    // are real server-side; only the label transition is timed. (see guardrail #5)
    const flip = setTimeout(() => setPhase('querying'), 650);
    // Backend text2sql op returns {generatedSql, data, executionMs, scannedBytes}.
    // If run() is wired to the plain athena passthrough, swap in the text2sql op here.
    const res: any = await run(text, { mode: 'text2sql' });
    clearTimeout(flip);
    setSql(res?.generatedSql ?? null);          // SINGLE SOURCE OF TRUTH — never reconstruct
    setPhase(res?.error ? 'error' : 'done');
    setFirstRunDone(true);
  }, [run]);

  return (
    <div className="max-w-[1400px] mx-auto">
      {/* Header */}
      <div className="mb-5">
        <h2 className="text-xl font-bold text-text-primary tracking-tight mb-1">Ask the Datalake</h2>
        <p className="text-[13px] text-text-tertiary">
          Natural-language questions, generated to SQL by Claude, executed on Athena over Iceberg
        </p>
      </div>

      {/* Input */}
      <div className="flex items-center gap-3 mb-3">
        <div className="flex-1 flex items-center gap-2 bg-surface-primary border border-border rounded-lg px-3 py-2">
          <Search size={14} className="text-text-muted" />
          <input
            type="text"
            value={question}
            onChange={(e) => setQuestion(e.target.value)}
            onKeyDown={(e) => e.key === 'Enter' && ask(question)}
            className="flex-1 bg-transparent text-[13px] text-text-primary outline-none placeholder-text-muted"
            placeholder="Ask a question about the datalake..."
          />
        </div>
        <button onClick={() => ask(question)} disabled={loading}
          className="px-4 py-2 text-[12px] font-bold text-white bg-accent rounded-lg hover:bg-accent-hover transition-colors uppercase tracking-wide disabled:opacity-50">
          {loading ? <Loader2 size={14} className="animate-spin" /> : 'Ask'}
        </button>
      </div>

      {/* Example chips */}
      <div className="flex flex-wrap gap-2 mb-5">
        {EXAMPLES.map((q) => (
          <button key={q} onClick={() => ask(q)} disabled={loading}
            className="text-[11px] font-mono px-2.5 py-1 rounded-full bg-surface-secondary text-text-tertiary border border-border hover:text-text-primary hover:border-border-strong transition-colors disabled:opacity-50">
            {q}
          </button>
        ))}
      </div>

      {/* Two-phase loading strip */}
      {(phase === 'generating' || phase === 'querying') && (
        <div className="flex items-center gap-2 mb-4 text-[12px] font-mono text-text-muted">
          <Loader2 size={13} className="animate-spin text-accent" />
          {phase === 'generating'
            ? <span><Sparkles size={11} className="inline mb-0.5 mr-1" />generating SQL...</span>
            : <span><Database size={11} className="inline mb-0.5 mr-1" />querying Athena over Iceberg...</span>}
        </div>
      )}

      {/* Generated SQL reveal — shown for done AND error (honesty contract) */}
      {sql !== null && (phase === 'done' || phase === 'error') && (
        <GeneratedSqlPanel sql={sql} defaultOpen={!firstRunDone || phase === 'error'} />
      )}

      {/* Error */}
      {phase === 'error' && error && <ErrorBanner sql={sql} error={error} />}

      {/* Results */}
      {phase === 'done' && !error && (
        rows.length === 0
          ? <p className="text-[12px] text-text-muted font-mono py-8 text-center">Query ran . 0 rows</p>
          : (
            <div className="bg-surface-primary border border-border rounded-xl overflow-hidden">
              <div className="px-4 py-2 border-b border-border flex items-center justify-between">
                <span className="text-[11px] font-mono text-text-muted">
                  {rows.length} rows{scannedRows != null ? ` . ${scannedRows.toLocaleString()} scanned` : ''}
                </span>
              </div>
              <ResultsTable rows={rows} />
              {executionMs != null && (
                <p className="text-[9px] font-mono text-text-muted text-right px-4 py-1">
                  Athena over Iceberg . {executionMs}ms
                </p>
              )}
            </div>
          )
      )}
    </div>
  );
}

// --- GeneratedSqlPanel (skeleton) ---
function GeneratedSqlPanel({ sql, defaultOpen = false }: { sql: string | null; defaultOpen?: boolean }) {
  const [open, setOpen] = useState(defaultOpen);
  const [copied, setCopied] = useState(false);
  const copy = () => { if (sql) { navigator.clipboard.writeText(sql); setCopied(true); setTimeout(() => setCopied(false), 1500); } };
  return (
    <div className="bg-surface-primary border border-border rounded-xl overflow-hidden mb-4">
      <div className="px-4 py-2 border-b border-border flex items-center justify-between">
        <button onClick={() => setOpen(!open)} className="flex items-center gap-2 text-[11px] font-bold text-text-primary uppercase tracking-wide">
          {open ? <ChevronDown size={13} /> : <ChevronRight size={13} />}
          Generated SQL
          <span className="text-[9px] font-mono text-text-muted normal-case tracking-normal">
            generated by Claude, executed on Athena over Iceberg
          </span>
        </button>
        <button onClick={copy} className="flex items-center gap-1 text-[10px] font-mono text-text-muted hover:text-text-primary">
          {copied ? <Check size={12} className="text-status-success" /> : <Copy size={12} />}
          {copied ? 'copied' : 'copy'}
        </button>
      </div>
      {open && (
        <pre className="px-4 py-3 text-[12px] font-mono text-text-secondary whitespace-pre-wrap overflow-x-auto bg-surface-secondary">
          {sql ?? 'SQL unavailable'}
        </pre>
      )}
    </div>
  );
}

// --- ResultsTable (generic rows->columns skeleton) ---
function ResultsTable({ rows }: { rows: Record<string, any>[] }) {
  const cols = Object.keys(rows[0] ?? {});
  const isNum = (v: any) => typeof v === 'number' || (typeof v === 'string' && v.trim() !== '' && !isNaN(Number(v)));
  // majority-numeric per column -> right-align
  const numCols = new Set(cols.filter((c) => rows.filter((r) => isNum(r[c])).length > rows.length / 2));
  const fmt = (v: any) => {
    if (v == null) return '∅'; // empty-set glyph
    if (typeof v === 'object') return JSON.stringify(v);
    const s = String(v);
    return s.length > 60 ? s.slice(0, 59) + '…' : s;
  };
  return (
    <div className="overflow-x-auto">
      <table className="w-full text-[12px]">
        <thead className="sticky top-0 bg-surface-secondary">
          <tr>{cols.map((c) => (
            <th key={c} className={`px-3 py-2 font-mono uppercase text-[10px] text-text-muted ${numCols.has(c) ? 'text-right' : 'text-left'}`}>{c}</th>
          ))}</tr>
        </thead>
        <tbody>
          {rows.slice(0, 100).map((r, i) => (
            <tr key={i} className="even:bg-surface-secondary hover:bg-surface-tertiary border-t border-border">
              {cols.map((c) => {
                const num = numCols.has(c);
                const full = typeof r[c] === 'object' ? JSON.stringify(r[c]) : String(r[c] ?? '');
                return (
                  <td key={c} title={full}
                    className={`px-3 py-1.5 max-w-[280px] truncate ${num ? 'text-right font-mono tabular-nums text-text-primary' : 'text-text-secondary'} ${r[c] == null ? 'text-text-muted' : ''}`}>
                    {num && typeof r[c] !== 'object' ? Number(r[c]).toLocaleString() : fmt(r[c])}
                  </td>
                );
              })}
            </tr>
          ))}
        </tbody>
      </table>
      {rows.length > 100 && (
        <p className="text-[10px] font-mono text-text-muted text-center py-2">showing 100 of {rows.length.toLocaleString()} rows</p>
      )}
    </div>
  );
}

// --- ErrorBanner (skeleton) ---
function ErrorBanner({ sql, error }: { sql: string | null; error: string }) {
  return (
    <div className="bg-status-error-subtle border border-status-error/20 rounded-xl p-4 mb-4">
      <div className="flex items-center gap-2 mb-2">
        <AlertTriangle size={14} className="text-status-error" />
        <span className="text-[12px] font-bold text-status-error-text">Query failed</span>
      </div>
      <pre className="text-[12px] font-mono text-status-error-text whitespace-pre-wrap">{error}</pre>
    </div>
  );
}
```

## Key decisions / open items for the build
- **i18n**: no hook exists — hard-code English now (matches `DigitalThreadPage`); keys listed above.
- **Chart toggle**: pure enhancement; ship table-only in the walking skeleton, add chart after.
- **Two-phase label**: cosmetic pacing timer (~650ms) documented as such; both steps are real.
- **scannedBytes vs scannedRows**: `useDatalake` state exposes `scannedRows`; the text2sql result
  spec mentions `scannedBytes`. Use whichever the backend actually returns; **omit the clause if
  neither is present** — never show a fabricated cost number.
- Do NOT add a mock-data fallback (would fail demo-review); keep the explicit "not configured" error.
